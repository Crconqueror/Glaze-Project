1. Install Glaze tool from https://webvault.cs.uchicago.edu/sandlab/fawkes/files/glaze/Glaze-2.2-Windows.zip 

2. Create a folder for Images and another for Glazed Images

3. Populate the Images folder with X number of images

4. Setup Glaze tool with the desired parameters

5. Process the images from the Images folder and set output to Glazed Images folder

6. Check whether all images have been processed and rename if needed to match the original image

7. Run Glaze Quiz.html

8. Choose the corresponding folders

9. Begin

10. Compare score at the end
